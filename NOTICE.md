## Changes from Flectar Mail

The full change history is in the git log. In summary: renamed to Rustmail
(application ID `org.rustmail.mail`), Android and iOS targets and Flectar
service integrations removed, and Claws Mail style features added (local
Maildir/mbox/MH accounts, NNTP, filters, actions, OpenPGP/S/MIME privacy
options and more; see `ROADMAP.md`).

## Source code (AGPL section 13)

corresponding source from <https://github.com/btey/rustmail>. The
